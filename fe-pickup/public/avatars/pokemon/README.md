# Pokémon fallback avatars

These 128×128 WebP assets were resized from the corresponding `official-artwork`
PNGs in the [PokeAPI sprites repository](https://github.com/PokeAPI/sprites).

Pokédex numbers: Bulbasaur 1, Charmander 4, Squirtle 7, Pikachu 25, Vulpix 37,
Jigglypuff 39, Psyduck 54, Ditto 132, Eevee 133, Snorlax 143, Mew 151, and
Togepi 175.
